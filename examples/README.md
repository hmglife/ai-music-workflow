# Examples

Reference material to help a new audio designer get started. These are **samples only** — they are
not used by the skill at runtime.

## sample_briefs/
Three anonymized, real-world music requirement documents (a CG brief, a Lobby brief, a Story brief).
All project / character / studio / composer names have been redacted to generic placeholders
(GameX, Character A, <composer>, <reference track>).

Use them in two ways:
1. **As distillation input** — copy them into `data/inbox/` and run the skill's Stage 1 to see how a
   profile is distilled (or use them alongside your own documents).
2. **As a format reference** — open them to see the field layout the templates are based on:
   - CG briefs have a two-part layout: metadata fields + a `Time | Requirements List` timeline block.
   - Lobby / Story / Login briefs are a single vertical field list.

When you have your own real documents, prefer distilling from those — your profile will be far more
accurate.
