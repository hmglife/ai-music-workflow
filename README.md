# ai-music-workflow

> 给**游戏音频策划**的 AI 音乐设计工作流 —— 一个 [WorkBuddy](https://www.workbuddy.cn) Skill。
>
> *An AI-assisted music design workflow for game audio designers.*

把一句「想要个紧张点的大厅音乐」，变成一份**排版和你手写的一模一样**的专业需求文档；
再按需转成 AI 作曲工具的精准提示词，或转成给音乐公司的修改反馈文档。

---

## 它解决什么问题

音频策划的日常不是写文档，但**文档写不清楚，返工的是整个制作周期**。这套工作流针对三件事：

| 痛点 | 它怎么做 |
|---|---|
| 每次写需求都在重新组织语言，风格还不统一 | 先**学习你过往的真实文档**，之后按你的语气、术语、字段习惯来写 |
| 手动排版 Excel，字体行高总是对不齐 | **填充你自己的模板**而非新建表格，字体、行高、列宽原样继承 |
| 参考图、录屏、临时曲散落在聊天记录里 | 自动归档成**能整包发给音乐公司的交付文件夹** |

产出长这样——不是一个孤零零的 Excel，而是对方拿到就能开工的一整包：

```
项目_类型_日期/
├── 项目_类型_日期.xlsx   需求文档（版式 = 你的模板）
├── Image/                概念图、关键视觉
├── Video/                参考录屏
├── Audio/                临时参考曲、哼唱
└── ASSETS.md             每个素材是什么、为什么重要
```

---

## 三个阶段，各自独立

你需要哪一步就用哪一步，它不会硬拉着你往下走。

1. **学习你的风格** —— 读你过往的需求文档，提炼出写作语气、审美倾向、各音乐类型的惯例
2. **生成需求文档** —— 一句想法 → 结构完整、版式统一的 Excel（日常主要用这个）
3. **把需求往下走** —— 分两条路：
   - **交给 AI 作曲** → 生成 Suno / Lyria 的精准提示词（严格依据各平台官方文档，附调优建议）
   - **交给音乐公司** → 听完成品后生成结构化的修改反馈文档

## 安装

1. 到 [Releases](../../releases) 下载最新的 `ai-music-workflow-x.y.z.zip`
2. 解压，把整个 `ai-music-workflow` 文件夹放进 WorkBuddy 的技能目录：
   - 个人使用：`~/.workbuddy/skills/`
   - 团队共享：`<项目>/.workbuddy/skills/`
3. 没有第三步。

**不需要装 Python，不需要敲 `pip`。** 运行环境 WorkBuddy 自带，缺少的组件工作流会在需要时
自己补上——你不用处理这些。

然后在对话里说人话就行：

> 「帮我写一份 Lobby 音乐需求文档」
> 「把这个需求转成 Suno 提示词」
> 「我听了音乐公司做的成品，帮我写反馈」

完整上手请看 **[QUICKSTART.md](QUICKSTART.md)**（5 分钟），详细说明看 **[USAGE.md](USAGE.md)**。

## 关于自带模板

仓库里的三个 Excel 模板带着**某一个团队**的版式（字体、行高都是那个团队的）。
强烈建议换成你自己的——把一份你写过的真实需求文档给它，说一句
「用这份文档做成我的 CG 模板」即可，字体、行高、列宽、边框会原样保留，只清空内容。

---

## 隐私

这个工作流会学习你的真实工作文档，所以隐私边界是硬性设计，不是口头承诺：

- **你的画像存在技能文件夹外面**（`~/.workbuddy/ai-music-workflow/`），升级技能不会弄丢它，
  分享技能也不会把它带出去
- **你的源文档**（`data/inbox/`）永远留在本地
- 打包脚本会在生成压缩包后**重新开包自检**，发现任何私人文件就**删包并报错**，而不是只给个警告

仓库里的示例文档全部脱敏（`GameX` / `Character A` 这种占位）。

---

## 兼容性提醒

需求文档常常要发给外部音乐公司，所以有一条硬约束写在了设计里：**Excel 里的参考图必须是
传统嵌入图**。某些工具会写成 Excel 365 的「单元格内图片」，在旧版 Excel、WPS 和邮件预览里
会显示成 `#VALUE!` —— 对方打不开图，这份文档就废了一半。
